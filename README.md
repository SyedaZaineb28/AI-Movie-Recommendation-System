# AI Movie Recommendation System

This project is a content-based movie recommendation system developed using Python in Google Colab. The system recommends similar movies based on movie characteristics such as genre, keywords, tagline, cast, and director.

## Techniques Used
- TF-IDF Vectorization
- Cosine Similarity
- Content-Based Filtering
- Flexible Movie Title Matching

## User Interface
The system includes an interactive interface that allows users to enter a movie title and receive five recommendations. A dropdown interface was also added to make movie selection easier and improve usability.

## Technologies
- Python
- Pandas
- Scikit-learn
- ipywidgets
- Google Colab

## Dataset
The project uses the Movies Recommendation dataset provided by YBI Foundation.

## Purpose
This project demonstrates how AI-based recommendation techniques can be combined with human-computer interaction principles to create a simple and user-friendly recommendation system.
